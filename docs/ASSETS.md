# 默认梗图包说明

默认包 `whale-community`（鲸鱼娘二创梗图）随插件分发，首次运行播种到 `DSH_HOME/memes`。

> 素材为用户提供的社区二创鲸鱼娘同人图，仅用于本地/私有仓库。版权归原作者；公开分发或商用前请先确认授权。

## manifest.json 格式

```json
{
  "pack": {
    "id": "whale-community",
    "name": "鲸鱼娘二创梗图",
    "description": "社区二创版鲸鱼娘梗图……"
  },
  "stickers": [
    {
      "file": "doomed.webp",
      "name": "DeepSeek完蛋了",
      "meaning": "翻车、崩了、想跑路时用……",
      "tags": ["完蛋", "跑路", "翻车", "哭"],
      "width": 640,
      "height": 636
    }
  ]
}
```

- 支持 `png / jpeg / webp / gif`；单文件默认上限 1 MiB。
- `width` / `height` 可选；Host 会优先读 manifest，再尝试从 PNG/GIF 头解析。
- `pack.id` 变化 = 新默认包：插件加载时会自动移除旧 bundled 包及其素材文件并重新播种；**同 id 不会覆盖**用户改名/添加的内容。

## 如何替换成自己的梗图

1. 把图片放进本目录，改成上面的 manifest 结构（`pack.id` 换一个新值，例如 `my-memes-2`）。
2. `git commit` 后对插件行做一次 disable → enable 或重启 DSH；旧默认包会自动迁移。
3. 也可以完全不改代码：在表情面板里直接「添加表情 / 新建表情包 / 编辑含义」，运行时会存进 `DSH_HOME/memes`。

## 生成脚本

本轮素材处理脚本在 `assets/_build/build-community-pack.py`（已 gitignore，不入库）。它会从 DSH attachment 存储读取用户提供的原图，生成 WebP、`manifest.json`、`icon.png` 与 `preview.png`。若需要长期维护，可把脚本移入 `tools/` 并去掉 ignore。
